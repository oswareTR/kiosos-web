# kiosos-web

Static marketing site for **[kiosos.com](https://kiosos.com)** — Phase 1 of the [Kiosos roadmap](https://github.com/oswareTR/kiosos-vault/blob/main/roadmap/sequencing.md).

## Stack

- **[Astro 7](https://astro.build/)** (Vite, TypeScript)
- **GitHub Actions** → **GitHub Pages**
- SEO: shared layout meta, canonical URLs, sitemap integration

See [docs/001-stack-and-local-dev.md](docs/001-stack-and-local-dev.md).

## Quick start

```bash
npm install
npm run dev
```
